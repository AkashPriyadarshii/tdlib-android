# Contact & Support — tdlib-android

> Official contact, issue reporting, and security disclosure channels for tdlib-android.

## Technical Support & Bug Reports

For compile failures, ABI relocation issues, Gradle configuration errors, or feature requests:
- **GitHub Issues:** https://github.com/AkashPriyadarshii/tdlib-android/issues
- **GitHub Discussions & Pull Requests:** https://github.com/AkashPriyadarshii/tdlib-android/pulls

## Security Vulnerability Disclosures

If you discover a security vulnerability in the prebuilt binary packaging, CI workflow integrity, or JNI bindings:
- **Security Advisories:** https://github.com/AkashPriyadarshii/tdlib-android/security/advisories
- Please do not disclose vulnerabilities publicly before a coordinated fix is merged.
