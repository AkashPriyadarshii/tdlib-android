Set Up TDLib on Android in 3 Steps

No NDK. No compiling TDLib from source. A prebuilt 4-ABI AAR plus a Kotlin Coroutines/Flow wrapper. Tracks TDLib upstream automatically.

Step 1 — add the dependency

Point Gradle at the prebuilt AAR

Add the core module — it bundles libtdjson.so for all 4 ABIs (arm64-v8a, armeabi-v7a, x86_64, x86). Add ktx for the coroutines wrapper.

// settings.gradle.kts
dependencyResolutionManagement {
  repositories { google(); mavenCentral() }
}

// app/build.gradle.kts
dependencies {
  implementation("io.github.tdlib-android:core:1.8.64")
  implementation("io.github.tdlib-android:ktx:1.8.64")
}
Step 2 — load the native library

Boot a TdClient

Load the JNI bridge, then create the client with your database path and Telegram API credentials from BuildConfig.

System.loadLibrary("tdjni")

val client = TdClient(
  filesDir = context.filesDir.absolutePath + "/tdlib",
  verbosityLevel = 1,
  apiId = BuildConfig.TELEGRAM_API_ID,
  apiHash = BuildConfig.TELEGRAM_API_HASH
)
client.init()
Step 3 — react to updates

Collect updates as a Flow

The ktx wrapper exposes MTProto updates as a hot Flow<TdApi.Update>. Handle them with coroutines, or use send(function) for typed requests.

CoroutineScope(Dispatchers.IO).launch {
  client.updates.collect { update ->
    // handle incoming MTProto updates reactively
  }
}

Runtime ~2 minutes. For the full docs, CI architecture, and the release pipeline, see the GitHub repository.
