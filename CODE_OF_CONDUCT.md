# Code of Conduct

## Our Standard

We want `tdlib-android` to be a practical, welcoming space for developers building Telegram-powered Android apps. We expect everyone who participates in issues, pull requests, and discussions to treat other contributors with basic respect.

## Expected Behavior

- **Focus on the technical problem**: Base technical disagreements on code quality, performance, correctness, and architecture.
- **Respect time**: Maintainers and contributors work on open-source projects in their free time. Open focused, actionable issues with logs, minimal reproductions, and clear context.
- **Constructive code reviews**: Provide actionable feedback on pull requests. Explain why a change helps or hurts the codebase.
- **Credit prior work**: Acknowledge upstream TDLib authors and original patch creators where applicable.

## Unacceptable Behavior

- Personal attacks, derogatory remarks, or insulting language.
- Harassment of any kind, whether public or private.
- Publishing private information of other contributors without consent.
- Spamming issues, pull requests, or discussions with low-value or abusive messages.

## Enforcement & Reporting

The maintainers of this repository oversee project communications and retain the right to edit, close, or delete issues, comments, and pull requests that violate these standards. Persistent violations may lead to temporary or permanent bans from the repository.

To report inappropriate conduct, contact Akash Priyadarshi directly on GitHub ([@AkashPriyadarshii](https://github.com/AkashPriyadarshii)).
